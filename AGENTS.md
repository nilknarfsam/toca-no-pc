# Trabalho neste projeto

- O agente principal coordena a tarefa, implementa as alterações e verifica a entrega.
- Delegue ao Terra uma revisão independente do trabalho. O Terra revisa os arquivos sem editá-los e relata os achados com os caminhos e as linhas relevantes.
- O agente principal decide como tratar os achados, aplica as correções e repete as verificações necessárias.
- Use somente o Terra para a revisão delegada.
